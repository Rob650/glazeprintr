# GlazePrintr Bot — Technical Specification

**Version:** Week 5 (April 2026)  
**Account:** @PrintrGlazr  
**Runtime:** Railway / Docker (Python 3.11)

---

## Overview

GlazePrintr is an autonomous Twitter/X bot that acts as the official voice of the Printr ecosystem — a Solana-native multi-chain token launchpad with proof-of-burn (POB) staking mechanics. The bot monitors 16 ecosystem tokens in real time, generates intelligence-driven original tweets, quote-tweets influencer content, replies to mentions, and scores community members' glaze levels. All content is generated by Claude (Anthropic) and grounded in live on-chain data from DexScreener and the Printr Partner API.

## Core Features

### Original Tweets (60-minute cycle)

The primary content engine. Every cycle:
1. Scrapes all 16 tokens from DexScreener (price, volume at 5m/1h/6h/24h, buys/sells, MC, liquidity)
2. Fetches staking data from Printr Partner API
3. Runs intelligence refresh → gets heat scores, top movers, ecosystem health
4. Builds `historical_context` from: active setups, triggered macro rules, 7-day comparisons, divergence analysis, smart wallet summary
5. Optionally includes macro context (35% chance) and competitor context (20% chance if enabled)
6. Passes full context to Claude → generates tweet in one of 7 style modes
7. Posts with optional meme image; records tweet ID and posted hour for performance tracking

If ENABLE_THREAD_MODE is on and a token has heat ≥85 and 24h move ≥50%, a 3-tweet thread fires instead (max 2/day).

### Quote Tweets — QT Glazer (30-minute cycle)

Polls Twitter List `2048242501333799282` for new tweets from curated CT influencers.

For each new tweet:
1. Glaze-scores the tweet (0-100) using Claude
2. If score ≥ threshold, generates a QT reply with optional meme
3. Posts via URL-paste method (appends tweet URL so Twitter auto-embeds QT card)
4. Records QT tweet ID + score

### Mention Replies (5-minute cycle)

Polls Twitter mentions and (if X_LIST_ID set) a follower keyword list.

For each mention:
1. Fetches tweet chain for context
2. Classifies intent (question / alpha request / compare / general)
3. Selects reply mode: hype / dunk / educate / chaos
4. Generates reply with full token data context
5. Posts reply; records in `replied_tweets` table

Limits: 5 replies/account/hour, 120-minute mention age cutoff, skips own handles.

### Glaze Score Tweets

When a mention tweet scores above the threshold:
1. Generates score card (0-100 with tier: S/A/B/C/D)
2. Creates meme image with tier badge
3. Posts as a QT of the scored tweet
4. Records in `glaze_scores` table (max 20/day)

## Intelligence System

### Token Ranking Engine — Heat Score (0–100)

Computed for every token every 15 minutes. Formula:

```
heat = (momentum_1h  × 0.25)
     + (momentum_6h  × 0.20)
     + (momentum_24h × 0.15)
     + (volume_surge × 0.15)
     + (buy_pressure × 0.10)
     + (staking      × 0.08)
     + (liquidity    × 0.07)
```

Each component is normalised to 0–100 before weighting. Tokens are ranked by heat score; the top 5 are prioritised as candidates for original tweets.

**Market Cap Tiers:**
- Whale: >$1M MC
- Mid: $100K–$1M MC
- Micro: <$100K MC

### Top Movers Detection

Thresholds evaluated every 15 minutes:

| Signal | Condition |
|--------|-----------|
| Pumping | 1h price change ≥ +20% |
| Dumping | 1h price change ≤ −15% |
| Volume Anomaly | 1h volume ≥ 3× hourly average |
| New ATH (proxy) | 24h change ≥ +50% AND 1h positive |
| Breakout | 24h change 10–49% AND 1h ≥ +5% |

### Historical Snapshots

- **Interval:** Every 15 minutes (piggybacks on intelligence refresh)
- **Retention:** 7 days (168 hours)
- **Fields stored per snapshot:** price, volume_1h, volume_24h, market_cap, buys_1h, sells_1h, staking_pct, liquidity

**Derived historical comparisons:**
- `volume_vs_7d_avg`: current 1h vol as multiple of 7-day hourly average
- `price_vs_7d_high`: current price % below 7-day high
- `price_vs_7d_low`: current price % above 7-day low
- `mc_rank_change`: token's ecosystem MC share change vs 7 days ago

### Setup Recognition (5 Patterns)

Evaluated against current + historical data:

| Setup | Conditions |
|-------|-----------|
| **Accumulation** | Volume spike ≥3× avg AND price flat (−5% to +5% 24h) |
| **Compression** | Staking up 5+ points over 7d AND volume declining to <80% of historical avg |
| **Laggard Catch-up** | Token underperforming ecosystem by 15+ points AND MC ≥$100K |
| **Breakout Confirmation** | 1h move ≥15% AND volume ≥2× avg AND buy dominance ≥70% |
| **Exhaustion Top** | 24h move ≥50% AND sell dominance in 2+ of last 3 snapshots |

### Macro Rules Engine (5 Rules)

Triggered when ecosystem-level conditions are met:

| Rule | Trigger |
|------|---------|
| `sol_bullish_week` | Ecosystem momentum ≥60 AND trending "up" |
| `staking_increasing` | Avg staking % increased 5+ points over 7 days |
| `volume_without_price` | 3+ tokens with 2× volume surge AND flat price (<5% 24h) |
| `mc_recovery` | Ecosystem MC dropped ≥20% from 7d high, now recovering ≥5% |
| `new_launches_spike` | 3+ new tokens launched in last 7 days |

### Ecosystem Health Dashboard

Computed from all 16 tokens:
- Total ecosystem market cap
- Total 24h volume
- Active token count (those with meaningful volume)
- Aggregate staking percentage
- Ecosystem momentum score (composite)
- Trending direction: up / flat / down

### Smart Wallet Profiling (6-hour refresh)

Pulls all staking positions from the Printr Partner API. Assigns **conviction scores (0–100)**:

```
conviction = lock_component (0–40)
           + diversification_component (0–30)
           + whale_size_component (0–30)
```

**Lock Duration Multipliers:**
| Duration | Multiplier | Lock Points |
|----------|-----------|-------------|
| 180d | 2.5× | 40 pts |
| 90d | 1.75× | 30 pts |
| 60d | 1.5× | 20 pts |
| 30d | 1.3× | 15 pts |
| 14d | 1.15× | 10 pts |
| 7d | 1.0× | 5 pts |

**Wallet Classifications:**
1. `max_conviction` — 180d+ locks with 2+ tokens staked
2. `whale_staker` — top 10% by total USD staked
3. `smart_accumulator` — new positions opened in last 7 days
4. `holder` — default

### Ecosystem Divergence

Computes tokens outpacing or lagging the ecosystem momentum. Surfaces "catch-up candidates" (lagging tokens with improving fundamentals) and "momentum leaders" (outperforming relative to ecosystem). Injected into the original tweet historical context.

### Buy Pressure Scoring

Component of the heat formula: `buys_1h / (buys_1h + sells_1h)` normalised to 0–100. A ratio of 70%+ buys counts as "buy dominance" for setup detection.

## Content Variety System

### 7 Original Tweet Style Modes

Claude picks ONE per tweet, rotates hard:

| Mode | Voice |
|------|-------|
| **GRINDSET** | Conviction as character trait — "weak hands don't lock 180d. they just don't." |
| **DEGEN REPORT** | Rapid-fire numbers, "something is happening RIGHT NOW" energy |
| **PHILOSOPHICAL** | What does belief/locking/conviction mean as a concept |
| **COMMUNITY CALLOUT** | Direct challenge — "if you've been watching and not acting, what are you waiting for" |
| **ABSURDIST HUMOR** | Ridiculous framing that makes the point land harder via comedy |
| **PRICE ACTION** | Chart-watcher voice — the number IS the opener, one line of context closes it |
| **HOT TAKE** | Contrarian frame that makes people stop scrolling and argue back |

### 4 Reply Style Modes

| Mode | Trigger | Voice |
|------|---------|-------|
| **hype** | Default (60%) | "I CANNOT BELIEVE I HAVE TO EXPLAIN THIS IN 2026" — glazed up with receipts |
| **educate** | Default (25%) | "Ser. SER. We talked about this." — data-backed education |
| **chaos** | Default (15%) | Unhinged glazer with a Bloomberg terminal, goblin mode |
| **dunk** | pump.fun/bonk keywords (100%) | Baffled, condescending, data-backed pity for the unglazed |

### Topic Rotation

- **4-topic cooldown:** last 4 topic keys excluded from original tweet selection
- **4-ticker cooldown:** last 4 tickers excluded to prevent back-to-back same-token tweets

### 5-Word Opener Fingerprint

First 5 words of each tweet are extracted, lowercased, and stored. The last 8 opener fingerprints are checked before generating a new tweet — if the new tweet's opener matches any prior, Claude is instructed to rewrite it. Prevents repetitive tweet openings.

### Recent Tweet Injection

The bot's own recent tweets are fetched and injected into the original tweet prompt. Claude is instructed to pick a different angle from anything posted in the last 2–3 tweets.

### Cross-Feature Token Cooldown

A 2-hour cooldown window prevents the same token from appearing across different features (original tweet, QT, whale alert, burn alert) in rapid succession.

- **Staking positions:** POST `/v1/staking/list-positions` (paginated, 100/page, max 60 pages)

- **Endpoint:** `https://api.dexscreener.com/tokens/v1/solana/{address}`
- **Price change intervals:** 5m, 1h, 6h, 24h
- **Volume intervals:** 5m, 1h, 6h, 24h
- **Transaction counts:** buys + sells at 5m, 1h, 6h, 24h
- **Additional fields:** priceUsd, marketCap / FDV, liquidity (USD), pairCreatedAt, chainId, dexId

Historical narrative knowledge of launchpad evolution injected into Claude prompts:
- **Era 1:** Pump.fun (Jan 2024) — 11.5M+ tokens, 1.4% graduation rate, $317M platform revenue

- **7 comparative narratives** covering staking yields, holder distribution, flywheel mechanics, anti-snipe evolution, survival rates, memecoin trajectories, and platform power tools

### Dune Analytics (optional)

- Configured via `DUNE_API_KEY` and `DUNE_QUERY_IDS` env vars
- Query results injected into original tweet context as `dune_context`

## Special Tweet Types

### Thread Mode

- **Trigger:** Token heat score ≥85 AND 24h price change ≥50%
- **Format:** 3-tweet thread — hook + data deep-dive + conviction close
- **Limit:** Max 2 threads/day
- **Image:** Meme image on first tweet only

### Correlation Tweets

- **Trigger:** 3+ tokens pumping or showing volume anomaly simultaneously
- **Content:** Claude generates a "multi-token momentum" observation
- **Cooldown:** 3-hour correlation cooldown between posts

### Staking Leaderboard

- **Cadence:** Every 12 hours (if ENABLE_STAKING_TWEETS)
- **Content:** Yield comparison across ecosystem tokens ranked by staking APY / conviction

### Whale Alerts

- **Trigger:** Token 1h volume ≥$5,000 USD AND ≥3× hourly average
- **Limit:** Max 3 whale tweets/hour
- **Supply threshold:** Wallets with >5% of supply flagged

### Burn Tracking

- **Source:** Printr Partner API `/v1/telecoin/buyback-burn-detail`
- **Trigger:** New `tx_hash` not previously recorded AND burn amount ≥$100 USD
- **Limit:** Max 2 burn tweets/hour
- **Cadence:** Every 30 minutes

### Launch Detection

- **Trigger:** New Solana token with contract ending in `brrr`, created within 2 hours, not in `KNOWN_CONTRACTS`
- **Limit:** Max 2 launch alert tweets/hour
- **Data captured:** contract_address, ticker, name, first_price, first_liquidity, fee_model

### Launch Guide Mode

- **Trigger:** Mention classified as "how to launch" intent AND ENABLE_LAUNCH_GUIDE is on
- **Content:** Step-by-step Printr launch guide as a reply

### Competitor Comparison

- **Platforms:** pump.fun and LetsBonk
- **Stats:** launches_24h, rugs_24h, avg_survival_hours, survival_rate_pct
- **Rug definition:** ≤−90% price drop OR liquidity <$50 after ≥0.5 hours
- **Cadence:** Every 2 hours

- Check `/health` endpoint (no auth required) — confirms bot is alive
